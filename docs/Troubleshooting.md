# Troubleshooting

## I cannot see a recurring task

Open the **recurring tab** and check that the recurring task is enabled and not archived. Daily, weekly, and monthly recurring tasks appear in their matching planning tab and view. Someday presets do not create tasks automatically; use the add action on the preset.

Also check the relevant tab and view, including the Tomorrow view or a previous time-period view if the task was moved or scheduled there.

## I moved a task by mistake

If the undo message is still visible, tap **Undo**. Otherwise, open the Task Info sheet or use the available swipe action to move the task back to the intended timeframe.

## I deleted or archived a task

Open the Settings sheet, then select **Trash**.

- Restore an archived task from the Archived list.
- Restore a recently deleted task from the Deleted list.
- Deleted tasks remain restorable for 30 days before their identifying content is anonymised.

## My tasks are taking a while to sync

When you first install to-day on a new device, or return to the app after a while, iCloud may need time to catch up. Your tasks and changes may appear gradually, and syncing can continue even after the “iCloud syncing” message disappears. The message disappearing does not necessarily mean that all your data has finished loading.

Make sure your devices use the same Apple Account for iCloud and are connected to the internet. Leave to-day open and give it time to catch up.

## My tasks look different on another device

Make sure both devices use the same Apple Account for iCloud and that iCloud is available. Allow time for changes to sync, then reopen to-day on both devices.

Settings can also change what is visible. Compare options such as **Show completed tasks** and **Show archived tasks** in the Settings sheet on each device.

## I cannot find a group

A group appears when at least two visible tasks begin with the same group tag. Check that the tag is at the start of each title and uses a supported format, for example:

```text
[Home] First task
[Home] Second task
```

Also check whether one of the tasks was moved, completed and hidden, archived, or deleted.

## A task disappeared after I moved it

In to-day, moving a task can make it disappear from the current list immediately.

This usually means the task has moved to another view, not that it was deleted.

For example:

- Moving a task to **Today** removes it from **This Week** or **This Month**
- Moving a task to **This Week** removes it from **Today**, if it is no longer scheduled for today
- Moving a task out of a group may remove it from the current group view
- Archiving a task hides it unless **Show Archived** is enabled

When this happens, to-day usually shows a short message at the bottom of the screen.

You can tap that message to jump to the moved task.

If the task was moved into another group, tapping the message will first return you to the main list, then open the destination group and highlight the task.

If nothing seems to happen immediately, wait a moment before tapping again.

## What are the messages at the bottom of the screen?

Some actions show a temporary message at the bottom of the screen, such as:

- Task moved to Today
- Task moved to This Week
- Task moved to This Month
- Task moved to another group
- Task archived
- Task deleted

These messages often include an action, such as **Undo** or **Jump to task**.

Tap the message if you want to quickly find the task or undo the action.


## I cannot find an archived task

Archived tasks are hidden by default.

To see them again, open **Settings** and turn on **Show Archived**.

Archived tasks stay in the app unless you permanently delete them.


## A recurring task came back

Recurring tasks create new tasks automatically based on their repeat setting.

If a recurring task appears again, check whether it is:

- A new occurrence created from the recurring task
- A task from a previous day, week, or month
- A restored task after Undo
- A task created on another device through iCloud sync

If you no longer want new tasks to be created, pause, archive, or delete the recurring task itself.


## The iCloud banner is showing

The iCloud status banner appears when to-day is waiting for, receiving, or applying iCloud changes.

This can happen when:

- You opened the app after using another device
- You made many changes quickly
- Your connection changed
- iCloud is catching up in the background

Most of the time, you can keep using the app normally while it syncs.

## A recurring task did not appear where I expected

Recurring tasks follow the app’s start of day, start of week, and start of month settings.

For example, if your week starts on Monday, weekly recurring tasks are created for that app week.

If something seems missing, check:

- The recurring task is not paused, archived, or disabled
- You are looking in the right view: **Today**, **This Week**, or **This Month**
- Your start of day, week, or month settings match what you expect
- iCloud has finished syncing if you use more than one device

## The keyboard suggestions are not showing the group I expected

Group suggestions are based on the current view.

This means suggestions in **Today** may be different from suggestions in **This Week** or **This Month**.

This keeps suggestions more relevant, but you can tap ``...`` to see all the groups from all views and tabs.
