# Task Notes and Checklists

Notes keep extra information and smaller steps with a task. Touch and hold the task to open **Task Info**, then tap **Add notes** or the existing note to edit it.

## Create a checklist

1. Open the task in **Task Info** and tap its note.
2. Tap the **checklist** button above the keyboard. This inserts `- [ ] `.
3. Type an item, such as `Bread`.
4. Press **Return** to start the next item, then type `Cheese`.
5. Tap the **checkmark** to save your note.

New checklist items start with a capital letter. Press Return on an empty list item to leave the list. Backspace also makes it easy to remove an empty checklist marker.

## Use a checklist

From the task list, tap the task's disclosure arrow to show its checklist. Tap an item's circle to mark it complete or incomplete. You can do the same in **Task Info**.

Checklist items are steps inside the note; they are separate from the task's own completion circle.

## Reorder checklist items

Open **Task Info** and expand its checklist if needed. Drag the handle beside an item up or down to change its position. You do not need to edit the note's Markdown to reorder the items.

## Format a note

The buttons above the keyboard add a **bullet list**, **numbered list**, **checklist**, or **link**. They are available in both the inline editor and the full-screen editor.

Press Return to continue a list at the cursor. You can also type Markdown directly:

```text
**Important**
*An extra detail*
- A bullet point
1. A numbered item
- [ ] An unfinished checklist item
- [x] A completed checklist item
[Website](https://example.com)
```

Saved notes display the formatting in Task Info and when expanded in the task list.

## Add or edit a link

Tap the **link** button to enter a name and web address. Select text or a web address first to prefill the link editor. To update an existing link, place the cursor inside it and tap the link button.

## Use the full-screen editor

While editing a note in Task Info, tap the expand control at the bottom-right of the note. Use the checkmark to save, or the cross to discard the full-screen editor's changes.

For a demonstration, open **Tips** in Settings and select **Checklists**, or follow the checklist tip link in **What's New**.
